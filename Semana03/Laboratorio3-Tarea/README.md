# Laboratorio 03: Registro de Notas

Aplicación desarrollada en Android con Jetpack Compose para calcular el promedio ponderado de 4 cursos, aplicando controles de estado como `Slider`, `Switch` y `Checkbox`.

## Funcionalidades
- **Sliders:** Asignación de notas enteras de 0 a 20 con badge en vivo.
- **Switch:** Control de opción para redondear el promedio final.
- **Checkbox:** Validación requerida para habilitar el botón de cálculo.
- **Tarjeta de Resultados:** Evaluación mediante `when` que determina la observación (*EXCELENTE*, *APROBADO*, *EN RECUPERACIÓN*, *DESAPROBADO*) y el color del Chip correspondiente.
